# CLP Roll of Honour verification

The CLP page now includes a verified recipient sequence from 2006 through 2024.

Sources used:
- YTAH's former WordPress uploads and surviving captioned CLP posts.
- Current Brickfields Asia College CLP programme records for the year-by-year Best Overall Student list.

Older photographs from 2006–2015 have been retained and paired to year-labelled YTAH media files.
Where YTAH's surviving caption data does not identify accompanying people, those faces are deliberately left unnamed.

The 2025 recipient has not been added to the roll in this package because currently surfaced third-party pages show an inconsistent spelling; add only once confirmed from YTAH/LPQB source material.
